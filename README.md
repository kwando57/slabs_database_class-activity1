

Introduction to Information Systems

Application: WhatsApp

(1.) The Five Pillars of Information Systems

1. Hardware

WhatsApp uses smartphones, computers, servers, and network devices to operate. These devices allow users to send and receive messages.

2. Software

WhatsApp is application software that runs on Android, iOS, Windows, and other supported operating systems. It uses software to send messages, make calls, and share files.

3. Data

WhatsApp collects data such as messages, phone numbers, contact information, timestamps, images, videos, and call information. The type of data collected depends on the feature being used.

4. People

The stakeholders include WhatsApp users, developers, system administrators, customer support staff, and Meta, the company that owns WhatsApp.

5. Process

The process begins when a user opens WhatsApp and sends a message. The system processes the message and delivers it to the recipient when possible.

(2.) Data and Information

Raw Data: The number of messages sent by each user during a day.

Information: A report showing the total number of messages sent during the day. This information can help administrators understand system usage and plan server capacity.
